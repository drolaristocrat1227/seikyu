# seikyu

カレンダーに付けた作業から請求書を作る、スマートフォン向けの静的Webアプリ（PWA）。

- 請求先ごとに分かれたカレンダーに、登録した項目（作業内容と単価）を日付単位で入力
- 期間を指定して請求書を作成（A4縦）。印刷、またはブラウザの印刷機能でPDF保存
- 発行した請求書は内容ごと履歴に残る
- オフライン動作

## データについて

- 入力内容は端末の localStorage にのみ保存され、どこにも送信されない
- 外部のサーバー・API・CDNは使用していない（CSPで自ドメイン以外への通信を禁止）
- 保存のたびに直前の状態を、1日1回その日の状態を端末内に控える（3日分）
- メニュー「バックアップ」からJSONファイルに書き出し／読み込みができる

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `app.js` | 本体 |
| `style.css` | 画面と請求書（印刷）のスタイル |
| `sw.js` | Service Worker（オフライン動作） |
| `manifest.json` | PWAマニフェスト |
| `icon-*.png` | アイコン |

ビルド不要。ファイルを置くだけで動く。
